# Class Website — ReactJS

A simple multi-view class website built with React, JSX, and Vite for the SWDFA501 practical assessment.

## Requirements
- Node.js and npm
- Git (for uploading to GitHub)

## Run locally
```bash
npm install
npm run dev
```
Open the local URL shown in the terminal.

## Build for deployment
```bash
npm run build
npm run preview
```

## Before submitting
1. Replace `YOUR SCHOOL NAME` in `src/App.jsx` with your actual school name.
2. Replace the sample student names and IDs in `src/Students.jsx`.
3. Replace the location and `info@example.com` in `src/Contact.jsx` with official details.
4. Test all navigation buttons and the counter.
5. Push the project to a public GitHub repository named `class-website`.
6. Import that repository into Vercel and deploy.

No CSS or styling framework is used, in accordance with the assessment instructions.
